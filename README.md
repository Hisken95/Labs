# Labs
Dette repositoryet inneholder praktiske IT-labs og prosjekter jeg gjennomfører
for å utvikle mine ferdigheter innen IT-support, nettverk, systemadministrasjon
og sikkerhet.

## Om

Jeg bruker dette repositoryet til å dokumentere:

- Hva jeg gjør
- Hvordan jeg konfigurerer systemer
- Problemer jeg møter
- Hvordan jeg feilsøker dem
- Hva jeg lærer underveis

## Labs

### Networking
Praktiske labs innen nettverk, protokoller, tjenester og feilsøking.

### Linux
Linux-administrasjon, konfigurasjon og troubleshooting.

### Windows
Windows-administrasjon og feilsøking.

### Hardware
Hardware-relaterte labs og feilsøking.

### Security
Labs relatert til IT-sikkerhet.

### PowerShell
Scripts og labs for PowerShell.

### Python
Scripts og mindre programmeringsprosjekter.
